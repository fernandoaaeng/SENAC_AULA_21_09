# Aula 21/09 — Requests, arquivos e o primeiro contato com a API

Material da UC11 para os alunos. O slide e os exercicios estao nesta pasta.
A aplicacao **NexusBank Corporate** e o professor quem sobe; na aula ele passa o IP.

## Como comecar (aluno)

1. Abra o slide no navegador (clique duas vezes no arquivo):

   `material_didatico/Requests, Arquivos e Brute Force — Aula 21 09.html`

2. Espere o professor subir o NexusBank e anotar o IP no quadro.
   Teste no navegador:

   - Interface: `http://IP-DO-PROFESSOR:8080`
   - API / saude: `http://IP-DO-PROFESSOR:8002/api/saude`
   - Swagger: `http://IP-DO-PROFESSOR:8002/docs`

3. Va para a pasta dos exercicios e siga o passo a passo:

   `exercicios_requests_arquivos/README.md`

## O que tem nesta pasta

| Pasta | Para que serve |
| --- | --- |
| `material_didatico/` | Slide da aula (HTML) e apostila de apoio |
| `exercicios_requests_arquivos/` | Scripts Python dos exercicios 1 a 10 |
| `banco_web/` | Aplicacao do laboratorio (o professor sobe) |

## Regra da aula

Use so o servidor do laboratorio, com o IP que o professor passar.
Nao aponte os scripts para site, sistema ou rede de terceiros.
