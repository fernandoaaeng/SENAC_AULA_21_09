## 🧭 Ordem sugerida

1. Leia `01_GUIA_PRATICO_INICIANTE.md` e rode `python github_c2_simples.py`.
2. Faça `01_EXERCICIOS_INICIANTE.md` (adicionar módulo, contar tarefas, salvar relatório).
3. Só então leia `02_GUIA_PRATICO_COMPLETO.md` (fiel ao `black-hat-python-cap7-github-c2.md`).
4. Faça `02_EXERCICIOS_COMPLETO.md` em laboratório com repositório **privado** de teste.

> ⚠️ Os scripts `git_trojan.py` e `modules/` da versão completa só devem ser executados contra repositório e máquina virtual de laboratório, com autorização do professor.
