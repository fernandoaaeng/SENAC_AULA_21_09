# Apostila — Requests, arquivos e ataques a senhas fracas

Material de apoio da UC11 (Desenvolver Algoritmos e Programação Estruturada para Servidores), curso Técnico em Segurança Cibernética — SENAC.

O objetivo é ligar três habilidades de Python que, juntas, aparecem o tempo todo em segurança: **falar com um servidor pela rede** (`requests`), **ler e gravar arquivos de texto** e **entender como senhas fracas são quebradas** — para depois **detectar** esse padrão nos logs (visão de defesa).

A aplicação-alvo da aula prática no repositório é o laboratório `banco_web_aula_21_09` (porta **8002**). Ela é propositalmente frágil e só deve ser usada **no laboratório, com autorização do professor**.
